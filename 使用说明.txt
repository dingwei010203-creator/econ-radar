Econ Radar · 会议与求职私人工作台
制作日期：2026-10-03

一、这是哪个版本
这是一个新的完整本地使用包，在原有会议静态版旁新增求职工作台。
它没有上传到 GitHub，也不会改变原有仓库或已部署网站的可见性。
请单独解压到新文件夹，不要直接覆盖此前设置过账号或 HTTPS 的目录。
本包仅监听 127.0.0.1，不是多人访问或公网部署版本，也没有登录功能。

二、启动（推荐，包含招聘监测）
1. 先关闭旧的 START.cmd 窗口，避免 8787 端口被占用。
2. 完整解压压缩包，进入 econ-radar 文件夹。
3. 双击 START.cmd，保持窗口打开。
4. 浏览器访问 http://127.0.0.1:8787 。
5. 默认进入求职概览；左侧“会议与投稿”进入原有会议页面。
需要已安装 Node.js 20 或以上版本；无需 npm install。
如果显示 EADDRINUSE，说明旧服务还在运行，请关闭旧窗口再启动。

三、离线方式
不运行服务也可以双击 web/index.html，浏览参考库、建立和编辑申请。
此模式不能自动获取官网内容；必须保留完整 web 文件夹及其中的脚本、资料。
离线文件、本地网址、localhost 与 127.0.0.1 可能属于不同的浏览器存储空间。
切换方式或更换设备前，导出 JSON 备份，在新的页面中导入。

四、建议第一次这样使用
1. “历史参考库”：搜索学校或研究方向，点击“查看原记录”。
2. 确认值得关注后，点击“建立申请”；原有他人的投递状态不会带入。
3. 打开招聘原文，确认本轮年份、岗位和截止日，再填写自己的进度。
4. 编辑申请时记录材料、推荐信、面试、Job talk 和下次跟进日期。
5. “求职概览”自动显示未来 14 天和已逾期的待办。
6. “来源与备份”导出 JSON 备份。CSV 适合 Excel 查看，JSON 才是完整备份。

五、已经实现的自动化
- 将提供的 Excel 历史记录转换为可搜索的参考库，保留文件、工作表、行号和原文。
- 参考记录一键建立个人申请，重复目标提示并打开已有记录。
- 汇总投递阶段、材料准备、推荐信、面试和跟进日期。
- 自动计算剩余天数，生成日期待办；已完成申请不再计入待办。
- 本地启动时、之后每 6 小时监测已启用的招聘列表；也可以立即检查。
- 提取网页招聘标题和链接，按链接去重，保存首次与最近发现时间。
- 显示每个来源的读取结果、失败原因和新增条数。
- 招聘线索按自定义关键词筛选，人工确认后建立申请。
- UTF-8 CSV 导入、CSV 导出、JSON 完整备份与合并恢复。

六、自动收集的范围与边界
目前是第一版“招聘列表监测”，不是全网智能搜索，也不能保证覆盖所有学校。
只读取配置的列表网页，不绕过登录、验证码或访问限制，不执行网页里的动态脚本。
默认 3 个来源来自旧模板。历史链接可能失效，实际可用性以运行结果为准。
可以在“来源与备份”增删来源；支持 edu.cn、gov.cn 和 aeaweb.org。
勾选、添加或移除后点击“保存来源设置”。最多保存 60 个，同时启用 20 个。
首次读取可能找到过去年度的公告，不代表都是新发布或仍可投递。
“首次发现”只表示系统收录时间，不能替代官方发布日期。
读取失败或未提取到链接时，不等于没有招聘；请点击来源到官网人工核对。
当前不自动确认岗位方向、资格和截止日期，不自动投递，不发送邮件和推荐信。
自动监测仅在电脑开机、联网且 START.cmd 持续运行时进行；未安装开机自启或后台计划任务。
关闭网页但保留 START.cmd，监测继续；关闭 START.cmd 或电脑后监测停止。
个人提醒显示在页面内，不会在关机时推送到微信或邮箱。

七、资料说明
内置 239 条历史参考记录、33 个招聘资料原文链接、17 份模板与经验文件。
239 条是来源行记录，不是 239 个当前有效岗位；不同表格可能记录同一所学校。
参考主要来自 工作岗位.xlsx、秋招结果.xlsx、推荐信发送方式.xlsx、Working_Job_求职.xlsx。
原有缺少年份的月日、无效日期和他人笔试/面试结果保留在参考原文，个人日期初始为空。
其他职业经验、院系评价和旧待遇资料以原文件供私人查阅，没有当作当前事实或自动择校评分。
会议页保留此前的静态快照，本次没有刷新会议信息。

八、保存在哪里
个人投递：当前浏览器 localStorage，键 econ-radar-private-jobs-v1。
招聘线索：data/feed.json；监测来源：data/sources.json。
历史参考：data/reference-seed.json 和 web/reference-data.js。
原始参考资料：web/references/。
导入 JSON 会合并记录：编号相同则以备份为准，其余当前记录保留。
导入 CSV 使用模板列名，日期为 YYYY-MM-DD；任何行校验失败，本次整批不导入。
CSV 导入不直接解析任意 XLSX 的排版；可从 Excel 另存为 UTF-8 CSV。
浏览器清理数据可能清除个人投递记录，请定期导出 JSON。

九、隐私
整个包包含私人参考资料。不要把整个包放入公开 GitHub 仓库或公开静态托管。
“私人使用版本”是使用方式说明，不是密码保护。拿到文件或能使用同一浏览器的人可以查看。
本次没有修改原 GitHub 仓库；此前仓库是否公开需另行处理。
