# 经济学会议雷达

独立静态页面，保留会议与期刊征稿的搜索、筛选和详情；数据来自 2026 年 10 月 3 日提供的快照，本次转换未重新核实通知。公开版删除私人求职、联系人和个人待办，保留 15 条会议及期刊记录。

## 发布

在仓库 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 / (root)，保存。免费个人账号使用 Pages 通常需要公开仓库；当前仓库的实际计划以设置页面为准。

启用后预计网址：https://dingwei010203-creator.github.io/econ-radar/

页面资源和数据全部内嵌，不连接后台或外部字体服务。点击来源或投稿链接会访问外部网站。国内直连需实际网络验证，不能保证所有地区和运营商稳定访问。

数据不会自动更新；更新需替换 index.html。此静态公开版没有登录保护。
