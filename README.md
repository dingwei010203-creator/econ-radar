# Econ Radar

经济学招聘与会议工作台。网站首页优先展示招聘信息，会议及征稿作为补充。

## 网站与更新

- GitHub Pages 入口：https://dingwei010203-creator.github.io/econ-radar/
- 招聘公开快照：`web/public-jobs.js`，页面显示最近一次检查时间。
- 会议公开快照：`web/conference-data.js` 与 `web/conferences.html`。
- 已配置每日外部检索任务；运行结果及是否完成同步，以每次实际执行情况为准。GitHub Pages 负责发布仓库中的静态文件，本身不负责检索招聘信息。
- 提交到 `main` 后，GitHub Pages 会构建和部署网站。可在仓库 Actions 中查看部署状态。

## 本地服务

`START.cmd` 启动的服务可检查已配置的本地招聘来源；仅在服务运行时工作。本地扫描结果不会自动写入 GitHub。

## 访问与个人记录

仓库和 GitHub Pages 当前是公开的，没有网站登录保护，仓库中的已有参考附件也可被访问。网页内新建的日程、投递和咨询记录保存在当前浏览器，不会自动同步至其他设备；换设备前请导出备份。招聘条件及日期以官方原文为准。GitHub Pages 在中国大陆的访问速度与稳定性取决于实际网络情况。
