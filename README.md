# Econ Radar

经济学招聘与会议工作台。个人投递、咨询、联系人及日程只保存在浏览器 localStorage，不发送到服务器。公开招聘快照与这些记录分开。

## 招聘来源与核实

`data/sources.json` 共13个官方来源，优先人口与劳动经济研究所、社科院总院、经济所、农发所、金融所、数量所、财经战略研究院及人大人事部、经济学院、应用经济学院。社科院入口以总院官方机构导航为依据：https://www.cass.cn/tongzhigonggao/ 。首页来源只能覆盖首页可见公告，不保证完整历史或附件岗位覆盖；人大人事部覆盖其他院系的公开招聘，但院系名称不能代表岗位性质。

只允许 edu.cn、gov.cn、aeaweb.org、cass.cn、cssn.cn、naes.org.cn 及其真实子域名；每次重定向都重新检查域名与公网IPv4。社科院报名平台 https://www.sydwgkzp.cn/cass 仅作为人工报名入口，不采集登录信息。

采集器按标准化URL去重（移除追踪参数、片段，合并人大导航别名），保留首次发现时间和多个来源编号。每源每轮最多读取4篇原文，按最久未读取顺序轮换；其余标题先收录。分类为学术岗位、博士后、行政或辅助、混合岗位、性质待核实。规则分类及日期自动提取都需人工确认，附件岗位表尚不自动解析。不从标题招聘年度推断发布日期，不从首次发现时间推断公告日期；多截止日期保留冲突证据，不猜具体岗位截止时间。截止当日仍需核实具体时分。

截至2026-10-09：官方原文已确认人大应用经济学院2024-12-03的教师招聘公告声明常年有效；社科院2026年第二批专业技术人员公告已于2026-06-05截止。两条由人工核对官方原文补入，明确标记为非采集器成功记录。人大2026-09-24招聘启事原文未成功读取，不能确定其岗位性质或当前有效性。

## 本地运行与测试

Node.js 24，无额外npm依赖。

```sh
node --test
node server.mjs
node scripts/scan.mjs
node scripts/build-pages.mjs
```

本地服务绑定127.0.0.1，启动及每6小时扫描；实时界面读取 `/api/feed`。单独扫描写入 `data/feed.json` 并导出白名单字段到 `web/public/feed.json` 和 `web/public/sources.json`。全部来源失败时返回退出码2，保留已有结果并记录失败；`lastCompletedAt` 表示尝试完成，不是成功采集时间。

## GitHub Pages更新

`.github/workflows/recruitment.yml` 在main更新、手动触发和每6小时计划触发时执行测试、扫描、提交两个公开快照并部署白名单构建目录。GitHub计划任务可能延迟；长期无活动可能暂停。工作流提交不会递归触发另一轮push工作流。静态页面按相对路径读取 `public/feed.json`，适配 `/econ-radar/web/` 子路径，不请求本地API。

仓库 Settings → Pages → Source 需要选择 **GitHub Actions**；Actions必须允许工作流读写contents，且github-pages环境允许main部署。此修改提供配置文件，不代表上述设置已启用或部署已完成。若保持旧的branch/root发布方式，页面仍可读取已提交公开快照，但该方式会公开仓库根目录中的其他文件。

Pages构建不包含 `web/references/`、`web/reference-data.js`原文件或 `data/reference-seed.json`，只生成空参考占位。同步命令只暂存两个公开快照，不读取任何浏览器备份、咨询、联系人或私人投递。不要将私人导出文件加入公开仓库。仓库此前已提交的历史参考资料仍存在于原分支与Git历史，本次未删除或改写历史；若其中不宜公开，应另行清理和处理既有暴露。

## 本轮实际验证限制

16项自动化测试通过。当前执行环境对13个官方来源全部出现DNS `EAI_AGAIN`，实时采集未成功；页面读取失败不能解释为没有招聘。搜索服务能读取总院官方导航、总院招聘原文及人大应用经济学院教师招聘原文，人口所等页面超时，人大人事部入口重定向异常。需在GitHub Actions或国内服务器重新运行扫描验证实际网络条件。本轮没有改变腾讯云服务、域名、HTTPS或登录配置。
